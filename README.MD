# Agro é Forte, Futuro Sustentável 🌱

## Sobre o Projeto
Projeto desenvolvido para o programa **Agrinho 2026**, com o tema **“Agro é forte, futuro sustentável”**. O objetivo é mostrar como o setor agropecuário é essencial para a economia, sociedade e meio ambiente, e como práticas sustentáveis podem garantir um futuro equilibrado para todos.

## Estrutura do Projeto
- `index.html` – Página principal do projeto.
- `main.js` – Script de funcionalidades, como scroll suave.
- `style/header.css` – Estilos específicos do cabeçalho.
- `style/style.css` – Estilos gerais do site.
- `images/` – Pasta com imagens usadas no projeto.

## Funcionalidades
- Layout responsivo
- Scroll suave na navegação
- Seções interativas com cards informativos
- Banner com imagem ilustrativa do campo sustentável

## Tecnologias Usadas
- HTML5
- CSS3
- JavaScript
